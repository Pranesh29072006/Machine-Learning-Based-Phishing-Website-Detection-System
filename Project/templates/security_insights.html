URL Threat Anatomy & Heuristic Feature Engineering

Academic and practical breakdown of Uniform Resource Locator manipulation techniques, lexical anomalies, and ensemble defense principles.

Subdomain Camouflage

Attackers prepend recognized brand names as leftmost subdomains (e.g. paypal.com.attacker-node.xyz). Users scanning only the front of the URL mistake the fake landing page for the legitimate corporate service.

Vector: num_subdomains • has_tld_in_subdomain

Direct IP Address Hosting

Hosting phishing kits on raw IPv4 or IPv6 addresses (e.g. http://192.168.1.1/login) avoids domain registration records (WHOIS) and bypasses DNS reputation blacklists. Legitimate commercial web services rarely expose raw IP logins.

Vector: has_ip_address

URL Shortening Cloaking

Shorteners like bit.ly, tinyurl.com, or t.co completely mask destination hostnames and path tokens. Adversaries leverage link shortening to defeat static email gateway filters and prevent pre-click domain inspection.

Vector: is_shortened (50+ known services)

Query Delimiter Obfuscation

Abnormal concentrations of query delimiters (?, =, &, %, ~, +, $) transmit base64-encoded session IDs, stolen victim emails, or dynamic malware routing arguments.

Vector: num_suspicious_symbols • num_query_params

Trademark Hyphen Spoofing

Hyphen-separated brand compounding (e.g. paypal-security-center-update.com) mimics official institutional infrastructure. Legitimate top brands rarely register complex hyphenated hostnames for core authentication portals.

Vector: num_hyphens • prefix_suffix_hyphen

HTTPS Protocol Misconceptions

Modern phishing kits frequently secure free automated TLS certificates (e.g. Let's Encrypt). While HTTP indicates clear transmission insecurity, HTTPS alone is no longer an absolute guarantee that a website is benign.

Vector: is_https (Contextual Weight: 9.27%)

The 17 Standardized Heuristic Features

Structured catalog of mathematical feature extractors analyzed during training and live inference
17 Feature Vectors
# Feature Identifier Data Type Adversarial Vector & Technical Rationale
01 url_length Numeric (float) Total character length of the raw URL. Phishing URLs frequently exceed 75 characters to embed redirect tokens or mimic complex enterprise paths.
02 domain_length Numeric (float) Character count of the registered hostname. Spoof domains often pad brand names with long descriptive keywords to deceive casual user inspection.
03 num_dots Numeric (float) Dot separator frequency. Multiple dots indicate nested subdomains or masked TLD structures commonly observed in spear phishing.
04 num_hyphens Numeric (float) Hyphen count across the full URL. High hyphen frequency indicates brand prefix/suffix squatting.
05 num_digits Numeric (float) Numeric digit count. High digit density signifies autogenerated hashes, victim tracking tokens, or dynamic malware routing endpoints.
06 has_ip_address Binary (0/1) Detects direct IPv4 and IPv6 literal hosts. Legitimate commercial web services rarely use raw IPs for public service delivery.
07 is_https Binary (0/1) Evaluates transport security encryption. Absence of TLS (HTTP) flags unencrypted plaintext data exposure.
08 has_at_symbol Binary (0/1) Detects the RFC 3986 @ user-info delimiter. Browsers disregard everything preceding @, routing the victim to the hostname following the symbol.
09 num_suspicious_symbols Numeric (float) Count of special symbols including ?, =, &, %, ~, +, $, #, !.
10 num_subdomains Numeric (float) Depth of nested subdomain levels beyond the second-level domain (SLD) and top-level domain (TLD).
11 is_shortened Binary (0/1) Evaluates whether the hostname matches over 50 prominent URL shortening services (e.g. bit.ly, tinyurl.com, t.co).
12 path_length Numeric (float) Character length of the directory path component. Deep nested directories often host disguised phishing credential landing pages.
13 num_query_params Numeric (float) Quantity of query string key-value parameters passed in the request string.
14 has_sensitive_keywords Numeric (float) Frequency of 24 sensitive keywords (e.g. login, verify, secure, banking, account, credential).
15 has_double_slash_redirect Binary (0/1) Checks for // occurring inside the path component, which causes open redirect vulnerabilities in modern web browsers.
16 prefix_suffix_hyphen Binary (0/1) Detects domain names containing internal or trailing hyphens separating brand names from deceptive action terms.
17 has_tld_in_subdomain Binary (0/1) Detects deceptive TLD strings (such as .com. or .org.) embedded inside subdomain segments.
