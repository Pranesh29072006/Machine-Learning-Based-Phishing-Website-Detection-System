Phishing Attack Anatomy: How Attackers Exploit URL Syntax

Threat Vectors

Phishing remains the primary initial attack vector in modern intrusions. Attackers exploit how human users and web browsers interpret Uniform Resource Locators (URLs) to trick victims into disclosing credentials, financial tokens, and session cookies.

Subdomain Camouflage

Attackers prepend trusted brand names as subdomains (e.g. paypal.com.attacker-domain.xyz) to visually deceive victims scanning only the leftmost portion of the URL.

URL Shortening Cloaking

Services like bit.ly or tinyurl mask the true destination domain, evading static email filters and preventing inspection until click-time.

Direct IP Address Hosts

Hosting credential harvesting kits directly on raw IPv4/IPv6 addresses avoids domain registration records (WHOIS) and bypasses DNS reputation filters.

Authentication '@' Bypass

RFC standards interpret anything preceding the @ character as user authentication information, redirecting the browser to the domain following the symbol.

The 17 Extracted Heuristic Feature Vectors

Feature Engineering

Our feature extractor standardizes URLs into a 17-dimensional mathematical vector analyzed identically during model training and live runtime inference.

1. Lexical & Structural Metrics

  • url_length: Total character length. Phishing links often exceed 75 characters.
  • domain_length: Length of registered hostname. Spoof domains typically inflate lengths.
  • num_dots: Frequency of '.' characters revealing nested subdomains.
  • num_hyphens: Hyphen counts rarely present in primary legitimate brands.
  • num_digits: Numeric digit frequency indicating session hashes or ports.
  • path_length: Directory depth of resource paths.
  • num_query_params: Count of query delimiters transmitting stolen data.

2. Heuristic Indicators & Syntax Anomalies

  • has_ip_address: Direct IPv4/IPv6 address indicator.
  • is_https: Indicator of secure protocol transmission.
  • has_at_symbol: Presence of '@' user-info override character.
  • num_suspicious_symbols: Count of ?, =, &, %, ~, +, $ characters.
  • num_subdomains: Subdomain depth beyond root domain hierarchy.
  • is_shortened: Match against known URL shortening service database.
  • has_sensitive_keywords: Presence of trigger words (login, verify, secure).
  • has_double_slash_redirect: '//' occurring within the URL path.
  • prefix_suffix_hyphen: Domain names containing leading or trailing hyphens.
  • has_tld_in_subdomain: TLD camouflage (e.g., .com embedded inside subdomains).

Project Objectives & Threat Landscape

Phishing remains the primary initial attack vector in over 85% of corporate credential compromises and ransomware deployments. Threat actors exploit human cognitive limits and browser address bar truncation by deploying complex subdomains, brand typo-squatting, and URL redirection techniques.

CodePulse AI establishes a pre-click defense perimeter. Rather than waiting for a user or browser to load remote HTML/JS payloads, the system extracts a standardized 17-dimensional lexical and structural feature vector, evaluating it against 100 trained decision trees to output calibrated risk scores in under 20 milliseconds.
